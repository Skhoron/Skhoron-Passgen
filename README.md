# Skhoron-Passgen

Генератор паролей с защитой от modulo bias (rejection sampling) и
хешированием/проверкой через Argon2id. Часть экосистемы [Skhoron](https://github.com/Skhoron).

## Что своё, а что библиотечное

| Компонент | Кто написал | Почему |
|---|---|---|
| Источник случайности (`OsRng`) | Библиотека (`rand`) | RNG нельзя изобретать самому — единственное место в крипто, где это категорически недопустимо |
| Rejection sampling (защита от modulo bias) | Свой код | Это арифметика, не крипто-примитив |
| Хеш-функция для паролей (Argon2id) | Библиотека (`argon2`) | Стандартизирована в RFC 9106, годы публичного анализа |
| Генерация соли | Библиотека (`password-hash`, внутри использует OsRng) | Соль — тоже случайные байты, тот же принцип, что и RNG |
| CLI, хранилище, работа с charset'ами, расчёт энтропии | Свой код | Обычная логика, не криптография |

Ни один криптографический примитив (RNG, хеш-функция) не написан
самостоятельно — только логика вокруг них.

## Возможности

```bash
# Просто сгенерировать пароль
skhoron-passgen generate --length 24

# Несколько вариантов на выбор
skhoron-passgen generate --length 20 --count 5

# Сгенерировать, показать один раз, сохранить хеш под меткой
skhoron-passgen new my-email-account --length 24

# Позже проверить, тот ли пароль ввели (например, что вы правильно
# записали/запомнили сгенерированный пароль)
skhoron-passgen verify my-email-account

# Список сохранённых меток
skhoron-passgen list
```

## Важно про хранилище

Файл хранилища (по умолчанию `skhoron-passgen-store.txt`) содержит
**только Argon2id-хеши**, не сами пароли — это безопасно хранить открытым
текстом, как `/etc/shadow`. Восстановить пароль из хеша не получится,
только проверить совпадение (пароль нужно самостоятельно сохранить в
момент генерации — он показывается один раз).

Метки (labels) в файле хранятся открытым текстом — если нужна
конфиденциальность и самих меток, рассмотрите шифрование файла целиком
отдельным слоем (например через XChaCha20-Poly1305), это не реализовано
здесь намеренно, чтобы не смешивать генератор паролей с полноценным
password-менеджером.
